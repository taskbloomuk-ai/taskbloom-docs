## Architecture

### MVC Pattern
```
Request → Router → Controller → Service → Model → Database
                     ↓
                  View (HTML)
```

### Service Layer
Business logic lives in `app/Services/`:
- **AuthService** - Authentication
- **TaskService** - Task operations
- **WalletService** - Financial transactions
- **VoucherService** - Voucher management
- **FraudDetectionService** - Security
- **CampaignService** - Campaign operations

### Database Layer
- Custom `Database` singleton (not ORM)
- PDO for all queries
- Prepared statements throughout
- Transaction support

27 base permissions + 7 extended permissions.

### Permission Categories

| Category | Permissions |
|----------|-------------|

## Extension Points

### Adding New Task Types
1. Add to `task_types` table
2. Define earning range
3. Set proof type (screenshot/link/none)
4. Configure in campaign wizard

### Adding New Permissions
1. Add to `permissions` table
2. Update `role_permissions`
3. Add to route definitions
4. Check in controller
