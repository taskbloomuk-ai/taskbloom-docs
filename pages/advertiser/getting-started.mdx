# Advertiser Getting Started

Welcome to TaskBloom as an advertiser! This guide will help you start creating campaigns and reaching real audiences.

---

## What You Can Do

As an advertiser on TaskBloom, you can:
- Create engagement campaigns with specific task types
- Target audiences by country and language
- Set budget limits and track spending
- Review and approve/reject task submissions
- Analyze campaign performance with detailed reports
- Manage vouchers for worker registration
- Fund your wallet and request withdrawals

---

## Quick Start Checklist

1. **Register** at `/advertiser/register`
2. **Fund your wallet** via `/advertiser/billing`
3. **Create your first campaign** at `/advertiser/campaign/new`
4. **Launch the campaign** and wait for task submissions
5. **Review submissions** at `/advertiser/tasks/review`
6. **Approve or reject** each submission

---

## Understanding Campaigns

A campaign is a **pool of tasks** that workers can access. Each campaign has:

| Property | Description |
|----------|-------------|
| **Name** | Your campaign identifier |
| **Task Type** | Type of work (review, follow, like, etc.) |
| **Budget** | Maximum amount to spend |
| **Cost per Task** | How much each completion pays |
| **Daily Cap** | Maximum tasks per day |
| **Target Countries** | Which countries can participate |
| **Target Languages** | Preferred languages |
| **Status** | draft, active, paused, completed |

---

## Campaign Workflow

> Draft → Launch → Active → Paused / Completed
