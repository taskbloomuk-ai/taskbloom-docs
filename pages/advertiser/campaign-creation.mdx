# Campaign Creation

Learn how to create your first advertising campaign on TaskBloom.

---

## Prerequisites

Before creating a campaign, ensure you have:

1. **Active advertiser account** - Registered and logged in
2. **Sufficient wallet balance** - At least minimum budget
3. **Campaign idea** - What task type and audience you want

---

## Step-by-Step Guide

### Step 1: Navigate to Campaign Creation

Go to **`/advertiser/campaign/new`**

### Step 2: Select Campaign Type

Choose from available task types. Each type has a specific payout range and proof requirement.

### Step 3: Configure Campaign Details

Fill in:
- **Campaign Name** - Internal identifier
- **Description** - Instructions for workers
- **Target URL** - Where workers go
- **Custom Instructions** - Additional guidance

### Step 4: Set Budget & Payout

| Setting | Description |
|---------|-------------|
| **Total Budget** | Maximum to spend (deducted from wallet) |
| **Cost per Task** | Payout per completion |
| **Daily Cap** | Max tasks per day (0 = unlimited) |
| **Manual Review** | Require approval? (Default: Yes) |

### Step 5: Define Targeting

| Setting | Options |
|---------|---------|
| **Countries** | Select specific countries or all |
| **Languages** | Filter by preferred language |
| **Min Account Age** | 0-365 days |

### Step 6: Launch

Click **Create Campaign** to save as draft, then **Launch** to make it active.

---

## Campaign Statuses

| Status | Meaning |
|--------|---------|
| **Draft** | Created but not launched |
| **Active** | Accepting task submissions |
| **Paused** | Temporarily stopped |
| **Completed** | Budget exhausted or manually ended |

---

## Common Issues

> **Error:** "Insufficient wallet balance"
> **Solution:** Deposit funds at `/advertiser/billing`
