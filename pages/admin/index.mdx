# Admin Getting Started

Welcome to TaskBloom administration. This guide covers your dashboard and key responsibilities.

---

## Admin Capabilities

As an administrator, you have full platform access:
- **User Management** - Create, edit, suspend, ban users
- **Campaign Moderation** - Approve, reject, pause campaigns
- **Task Verification** - Review pending submissions
- **Financial Management** - Process payouts, manage deposits
- **Voucher Management** - Generate, import, revoke vouchers
- **Package Configuration** - Manage subscription tiers
- **Analytics & Reports** - Platform-wide insights
- **System Settings** - Configure platform behavior

---

## Dashboard Overview

**URL:** `/admin/dashboard`

### Main Sections

| Section | Contents |
|---------|----------|
| **Platform Stats** | Total users, active campaigns, pending tasks, daily revenue |
| **Quick Actions** | Common admin tasks |
| **Recent Activity** | Latest system events |
| **Alerts** | Fraud warnings, approval queues, issues |

## Key Admin Routes

| Route | Function |
|-------|----------|
| `/admin/dashboard` | Main overview |
| `/admin/users` | User list and management |
| `/admin/campaigns` | All campaigns |
| `/admin/tasks` | Task approval queue |
| `/admin/payouts` | Payout processing |
| `/admin/vouchers` | Voucher management |
| `/admin/analytics` | Platform analytics |
| `/admin/settings` | System configuration |

---

## Permission System

Admins have all permissions by default:

| Category | Permissions |
|----------|-------------|
| User Management | manage_users, view_users, edit_users, delete_users |
| Task Management | manage_tasks, approve_tasks, reject_tasks, view_all_tasks |
| Campaign | manage_campaigns, create_campaign, edit_campaign, pause_campaign |
| Billing | manage_billing, process_payouts, view_payouts |
| Analytics | view_analytics, export_reports |
| System | manage_settings, manage_task_types |

## Daily Operations

### Morning Checklist
1. Check dashboard for alerts
2. Review pending task approvals
3. Process any pending payouts
4. Review campaign approval queue

### Weekly Tasks
- Review user ban appeals
- Check voucher inventory
- Monitor analytics trends
- Review system logs
