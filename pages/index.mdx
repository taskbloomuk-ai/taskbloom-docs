# TaskBloom Documentation

Welcome to the official guide for the TaskBloom platform. Whether you're here to earn, advertise, or distribute — you're in the right place.

---

## Quick Start

1. **Choose your path** — Worker, advertiser, or reseller
2. **Create your account** — Register with a valid voucher code
3. **Start using the platform** — Complete tasks, launch campaigns, or distribute vouchers
4. **Earn & grow** — Build your earnings and upgrade your package

| Feature | Description |
|---------|-------------|
| **Task System** | Complete micro-tasks — social follows, reviews, video views, surveys |
| **Campaign Manager** | Create targeted campaigns with specific demographics |
| **Voucher System** | Secure digital codes for registration and upgrades |
| **Wallet & Payouts** | Real-time balance tracking with flexible withdrawal options |
