# Getting Started with TaskBloom

Welcome to TaskBloom! This section will help you understand the platform and get set up quickly.

## What is TaskBloom?

TaskBloom is a **global microtask earning platform** where:

- **Advertisers** create campaigns to promote their products/services through real human engagement
- **Workers** complete simple tasks (watch videos, leave reviews, follow accounts) and earn money
- **Admins** ensure platform quality, handle moderation, and manage finances
- **Team Leads** approve worker submissions and manage quality control
- **Resellers** purchase vouchers in bulk to sell or distribute

## Key Concepts

### Tasks
Tasks are **micro-assignments** that workers complete for payment. Types include:
- Social media interactions (follow, like, view)
- Reviews and ratings
- App installations
- Survey completions
- Video watching

### Campaigns
Campaigns are **advertiser-created task pools** with specific:
- Targeting (countries, languages)
- Budget limits
- Task types
- Payout rates

### Vouchers
Vouchers are **digital codes** that:
- Allow worker registration
- Enable package upgrades
- Can be gifted between users

### Wallet
The wallet system handles:
- Task earnings accumulation
- Referral commission tracking
- Payout requests
- Transaction history

## Quick Start Checklist

> **Advertisers:** Register → Fund Wallet → Create Campaign → Launch
> **Workers:** Register (with voucher) → Find Tasks → Complete → Earn → Withdraw
> **Admins:** Login → Review Dashboard → Manage Users/Campaigns
