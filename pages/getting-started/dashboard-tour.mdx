# Dashboard Tour

Your dashboard is your command center. Here's what you'll find on each role's dashboard.

---

## Worker Dashboard

**URL:** `/tasks`

### Main Components

| Component | Location | Description |
|-----------|----------|-------------|
| **Stats Cards** | Top | Tasks completed, today's earnings, active tasks, pending approval |
| **Active Tasks** | Main area | Current task assignments |
| **Task Limits** | Sidebar | Daily/monthly remaining, earning progress |
| **Quick Actions** | Header | Get Task button, navigation |

### Key Metrics

- **Tasks Completed** - Total approved tasks
- **Today's Earnings** - Money earned today
- **Active Tasks** - Tasks in progress (locked/in_progress)
- **Pending Tasks** - Awaiting advertiser review
- **Remaining Daily Tasks** - Tasks available today
- **Remaining Monthly Tasks** - Tasks available this month
- **Current Earnings** - Progress toward monthly cap

### Navigation

| Link | Destination |
|------|-------------|
| `/tasks` | Main dashboard |
| `/tasks/available` | Get new tasks |
| `/tasks/history` | View all past tasks |
| `/wallet` | View balance & request payout |
| `/referrals` | View referral code & team |
| `/packages` | View/upgrade package |
| `/settings` | Account settings |

## Common Dashboard Elements

All dashboards share these features:

- **Header** - Logo, user menu, notifications, logout
- **Sidebar** - Role-specific navigation
- **Stats Widgets** - Role-appropriate metrics
- **Quick Actions** - Most common tasks
