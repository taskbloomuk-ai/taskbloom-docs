# Troubleshooting Common Issues

Find solutions to frequently encountered problems on TaskBloom.

---

## Registration Issues

### "A valid voucher code is required to register"

**Cause:** No valid voucher provided during signup

**Solution:**
- Contact an advertiser to provide a voucher
- Check if you received a promotional voucher

### "Email already registered"

**Cause:** Account exists with this email

**Solution:**
- Try logging in at `/login`
- Use a different email address
- Contact support if you lost access

---

## Task Issues

### "Daily task limit reached"

**Cause:** Used all daily tasks for your package

**Solution:**
- Wait until midnight (resets daily)
- Upgrade to a higher package for more daily tasks

### "Monthly task limit reached"

**Cause:** Used all monthly tasks

**Solution:**
- Wait until the 1st of next month
- Upgrade package for higher monthly limit

### "Monthly earning limit reached"

**Cause:** Hit your monthly earning cap

**Solution:**
- Package determines cap (Bronze: $11.99, Silver: $74.99, etc.)
- Wait until 1st of month for reset
- Upgrade to higher tier for higher cap

### "You have a task in progress"

**Cause:** Already have an active task

**Solution:**
- Complete current task first
- Or cancel it at `/tasks`

### "No tasks available right now"

**Cause:** No campaigns active in your region

**Solution:**
- Check back in a few minutes
- Campaigns may be paused or out of budget

---

## Wallet & Payout Issues

### "Insufficient balance for payout"

**Cause:** Balance below $10 minimum

**Solution:**
- Earn more by completing tasks
- Accumulate to $10 minimum

### "Payout pending for too long"

**Cause:** Standard 72-hour processing

**Solution:**
- Wait up to 72 hours
- Contact support after 7 days with payout ID

---

## Campaign Issues (Advertiser)

### "Campaign won't launch"

**Possible Causes:**
- Insufficient wallet balance
- Invalid task configuration
- Missing required fields

**Solution:**
- Fund wallet at `/advertiser/billing`
- Review campaign settings
- Check approval queue

### "No submissions on campaign"

**Possible Causes:**
- Campaign paused
- Budget exhausted
- No matching workers in targeting

**Solution:**
- Verify campaign is active
- Check remaining budget
- Expand target countries

---

## Login Issues

### "Invalid credentials"

**Solution:**
- Check email spelling
- Verify password (caps matter)
- Use "Forgot Password" if needed

### "Account locked/suspended"

**Solution:**
- Contact support@taskbloom.co.uk
- Check if ban appeal pending

## Error Reference

| Error Code | Solution |
|------------|----------|
| No active package | Purchase package at /packages |
| Daily limit reached | Wait for midnight reset |
| Monthly limit reached | Wait for 1st of month |
| Earning cap hit | Wait for monthly reset or upgrade |
| Concurrent task limit | Complete current task |
| Minimum payout $10 | Earn more first |
| Invalid payment method | Select valid option |
